# Nexus-AI-HARNESS 1.1.3

Исправления по аудиту: GUI, браузер, обучение.

## GUI
- `type_text` печатает строчные буквы, цифры, знаки препинания и эмодзи (UTF-16 surrogate pairs), а не только заглавные/пробел.
- `\n` и `\t` преобразуются в Enter/Tab.
- `SendInput` проверяет число принятых событий и возвращает ошибку с кодом Windows вместо тихого «нажал».
- `press` сообщает о неизвестной клавише; `focus` проверяет, что окно действительно вышло вперёд.

## Браузер
- Индексы `browser_snapshot` совпадают с реальными элементами: скрытые больше не сдвигают нумерацию.
- Клик/ввод повторяются один раз после перерисовки DOM (протухший handle).
- `alert`/`confirm`/`prompt` принимаются автоматически и показываются в снапшоте.
- `window.open` переключает работу на новую вкладку.
- Гонка при создании Playwright-потока закрыта; зависший вызов даёт явную ошибку вместо вечного ожидания.
- Занятый профиль Chrome даёт понятное сообщение.
- `browser_eval` требует подтверждения в режиме Act: произвольный JS в залогиненном профиле — риск.

## Обучение
- Проверка PID точная (`123` больше не считается живым из-за `1234`).
- Ошибка запуска тренера возвращается как 409 с текстом, а не 500.
- `/api/training/status` читает только новый хвост `run.log`, а не весь файл на каждый запрос.
