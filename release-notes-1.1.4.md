# Nexus-AI-HARNESS 1.1.4

Закрыты ещё четыре пункта аудита.

- `/api/config` проверяет типы: `workspace` — строка, `max_steps` — целое 1..200, `provider`/`model` — строки, `providers`/`browser` — объекты. Раньше `{"workspace": 123}` сохранялся и ломал первый же инструмент.
- SSE для несуществующей сессии отвечает 404, а не висит 200 с пустым потоком.
- `/api/training/start` проверяет числа и категории до сборки датасета: `"epochs": "abc"` больше не маскируется под «мало материала», неизвестная категория не означает «все категории».

Проверено на временном `NEXUS_ROOT`: SSE 404, workspace 400, max_steps 400, epochs 409 с `ev.trainBadParam`.
